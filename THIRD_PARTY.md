# Third-Party and Zeliard-Derived Material

This repository contains original work created for the web port as well as material derived from or originating in the original **Zeliard** game.

This document records the known provenance of third-party and Zeliard-derived material included in the repository. Where the exact provenance or authorship of a particular file is unknown, this is explicitly stated rather than inferred.

This document identifies material that is **not covered by the MIT License** included in this repository.

## Zeliard

**Zeliard** is a game developed by **Game Arts** and released for PC DOS by **Sierra** in 1990.

The original game was developed by Game Arts for NEC PC-8801 computers in Japan before its PC DOS release.

This project is an independent fan-made web port/reimplementation and is not affiliated with, sponsored by, or endorsed by Game Arts, Sierra, or their successors/rightsholders.

All rights in the original Zeliard game and its original intellectual property remain with their respective rights holders.

The inclusion of Zeliard-derived material in this repository does not imply that those materials are released under the MIT License.

## Music

The music included with this project originates from the PC DOS version of Zeliard.

The original game music is credited to:

* **Nobuyuki Aoshima**
* **Fumihito Kasatani**

The MIDI archive from which the music was obtained identifies the following sequencing credits:

* **Nobuyuki Aoshima**
* **Fumihito Kasatani**
* **Tom Lewandowski**

### MIDI archive attribution

The source archive identifies itself as a game rip and provides the following information:

```text
Archive created by -=MIRSOFT=-

Archiver: Quest Studios - www.QuestStudios.com
Type: Game rip
Format: MID (MT, GM)

Original Composer:
Nobuyuki Aoshima
Fumihito Kasatani

Sequencer:
Nobuyuki Aoshima
Fumihito Kasatani
Tom Lewandowski

Num of tunes: 14
```

The archive states that the MIDI tunes were ripped from the PC DOS version of Zeliard released by Sierra in 1990.

It further states:

* **MT** files are original tunes recorded directly from the game.
* **GM** files are General MIDI versions converted from the Roland MT-32 versions for playback on General MIDI sound cards.
* The MIDI files were recorded/converted to Standard MIDI File format by **Tom Lewandowski of Quest Studios**.

The archive also identifies:

```text
Game: Zeliard
Platform: PC DOS
Year: 1990
Publisher: Sierra
Developer: Game Arts
```

The original archive credits **Quest Studios** and references:

https://www.queststudios.com/
